# WICK DUEL

3D-дуэль на пистолетах с глушителем от первого лица для Telegram Mini App.
Костюм в стиле Джона Уика, посёлок Дикого Запада, кровь, отдельное здоровье
у каждой части тела (рука отвалилась — переключение на другую руку, нога —
персонаж заваливается на одну сторону), 3 уровня сложности ботов и онлайн-дуэли 1×1
со счётчиком игроков.

## Структура проекта

```
duel-game/
├── server.js          # Node.js + Express + Socket.io: онлайн-счётчик, матчмейкинг, релей боя
├── package.json
└── public/
    ├── index.html      # разметка, UI, подключение Telegram WebApp SDK
    ├── style.css        # стили интерфейса
    └── game.js          # весь игровой движок: Three.js сцена, "рагдолл"-части тела,
                          # кровь, пистолет, ИИ ботов, онлайн-логика
```

## Локальный запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000` в браузере (для полноценной проверки тач-управления
удобнее открыть через мобильный эмулятор Chrome DevTools).

## Деплой на Render

1. Залейте этот проект в свой репозиторий на GitHub.
2. На [render.com](https://render.com) создайте **New → Web Service**, подключите репозиторий.
3. Параметры сборки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. Render сам пробросит переменную `PORT` — сервер уже её слушает.
5. После деплоя получите URL вида `https://ваш-сервис.onrender.com`.

## Подключение к Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Команда `/newapp` (или "Bot Settings → Menu Button/Mini App") — укажите URL вашего Render-сервиса.
3. Игра откроется как Telegram Mini App, `Telegram.WebApp.ready()`/`expand()` уже вызываются в `index.html`.

## Игровые механики

- **Части тела:** голова (40 HP), торс (60 HP), руки и ноги (30–35 HP каждая).
  Смерть наступает при обнулении головы или торса — то есть "с одной пули" никто не
  умирает, персонажа нужно действительно расстреливать, как и просили.
- **Потеря конечности:** при обнулении HP руки она отделяется (физически падает через
  cannon-es) и стреляющая рука автоматически переключается на вторую, если та жива.
  При потере ноги персонаж (бот/оппонент) заваливается в сторону; для игрока от первого
  лица это выражается наклоном и понижением камеры.
- **Кровь:** частицы при каждом попадании + пятно-декаль на земле при отделении части.
- **Боты:** `easy` / `medium` / `hard` — разная скорость реакции, вероятность попадания
  в голову и вероятность промаха/попадания по конечностям вместо корпуса.
- **Онлайн 1×1:** `server.js` держит очередь ожидания, при появлении двух игроков создаёт
  комнату и ретранслирует позицию, выстрелы и попадания между клиентами. Счётчик
  "Онлайн" и "Сыграно дуэлей" транслируется всем подключённым через событие `stats`.

## Что стоит доработать дальше (сознательно упрощено ради компактности кода)

- Сейчас урон по онлайн-сопернику считает клиент стрелявшего игрока (`hit` от инициатора) —
  для честной игры на проде стоит перенести проверку попаданий на сервер (сервер знает
  положения обеих моделей и сам решает, было ли попадание).
- Модель тела сделана из примитивов (капсулы/боксы) в стиле низкополигональной
  графики — при желании подставьте свои GLTF-модели через `THREE.GLTFLoader`,
  просто замените `buildHumanoid()`.
- Наведение реализовано тач-драгом по экрану; при желании добавьте gyroscope-наведение
  через `DeviceOrientationEvent` для более "дуэльного" ощущения от первого лица.
